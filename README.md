# hello, world

Одностраничный сайт без зависимостей и сборки. Всё в `index.html`.

- буквы «магнитятся» к курсору: меняют вес (variable font), приподнимаются и подсвечиваются
- когда мышь не двигается — по надписи идёт волна
- клик / пробел — смена палитры (5 настроений)
- фон: три размытых пятна, одно следует за курсором
- уважает `prefers-reduced-motion`, работает на телефоне
